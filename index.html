Session d'écoute

      
Créez une session et envoyez le code à un ami : il verra en direct ce que vous écoutez, sur son propre appareil.

      
Deux façons d'écouter ensemble :

      
1. Sans Premium, chacun sur son Spotify : l'invité touche « Ouvrir ce titre dans mon Spotify » et lance le même morceau dans son application, gratuitement.

      
2. Le son direct depuis cette app : l'hôte (sur ordinateur, Chrome ou Edge) touche « Partager le son (audio seul) », choisit l'onglet (ou l'écran entier si le son sort de l'app Spotify de bureau) en cochant « Partager l'audio », et l'invité touche « Écouter le direct ». Seul le son est transmis : la piste vidéo est coupée immédiatement, aucune image de l'écran ne part chez l'invité. Le son arrive alors dans RezMusic, sans Spotify côté invité. Limites : iOS ne permet pas de capturer le son d'une autre application, le partage s'arrête si l'hôte ferme l'onglet, et certains réseaux très stricts (entreprises) bloquent la connexion directe.

Spotify ou YouTube ?

      
Les deux chemins fonctionnent, gratuitement. Spotify demande un compte (gratuit ou Premium) : la connexion marche dans les deux cas, seule la lecture audio dans l'app est réservée au Premium par Spotify. YouTube ne demande aucun compte Spotify — juste une clé API Google gratuite.

      

        
        
      

      

    


    

      
Mode de lecture

      
Choisissez ce que fait un appui sur ▶. Les extraits de 30 s sont un choix : activez-les ci-dessous pour faire apparaître le bouton « 30 » dans la recherche et dans le lecteur.

      

        
        
      

      
      
Non connecté

      
      
Chaque personne connecte son propre compte : le jeton Spotify est gardé uniquement dans ce navigateur et n'est jamais partagé, ni avec la session d'écoute, ni avec les autres visiteurs. Personne ne peut ouvrir ton compte depuis RezMusic, et tu ne peux pas tomber sur le compte de quelqu'un d'autre.

      
      
Appareil : ---- · connexion liée à ce navigateur

      

      
Client ID de l'application

      
Ce n'est pas un jeton personnel et tu n'as rien à créer : tu te connectes avec ton compte Spotify, le jeton est généré automatiquement. Ce champ sert seulement si le site affiche « Client ID invalide ». Colle ici le Client ID de l'application (32 caractères, depuis Spotify Developer Dashboard → ton app → Settings).

      
      

      
Tes amis n'ont aucun compte développeur à créer : en touchant « Se connecter avec Spotify », Spotify leur demande directement leur e-mail et mot de passe, exactement comme dans l'application Spotify normale. Seul le propriétaire du site crée l'application une fois (le Client ID ci-dessus).


      

        Aide : faire marcher la connexion Spotify pour tout le monde
        
    
          
  1. Le propriétaire du site ouvre Spotify Developer Dashboard → son application → Settings, copie le Client ID (32 caractères) et le colle dans le champ ci-dessus.
    2. 
          
  2. Dans Redirect URIs, ajouter exactement cette adresse : …
    3. 
          
  3. Dans User Management, ajouter le compte Spotify de chaque ami (5 comptes maximum en mode développement).
    4. 
          
  4. Pour écouter les morceaux en entier : compte Premium (règle de Spotify, pas un réglage de RezMusic).
    5. 
        

        
      

    


    

      
Mes playlists Spotify

      
Connecte ton compte Spotify pour importer tes playlists et tous leurs sons. Chaque ami se connecte avec son propre compte, en un clic. La lecture complète demande un compte Spotify Premium.

      

      

      
    


    

      
Recherche YouTube (sans Spotify)

      
Tu n'as pas de compte Spotify ? RezMusic peut chercher et jouer les morceaux avec YouTube, sans aucun abonnement. Il faut une clé API Google gratuite, enregistrée une fois.

      
      
      
Aucune clé enregistrée.

      

        Comment obtenir cette clé (gratuit, 5 minutes)
        
    
          
  1. Ouvre console.cloud.google.com et crée un projet.
    2. 
          
  2. « API et services » → « Bibliothèque » → active YouTube Data API v3.
    3. 
          
  3. « Identifiants » → « Créer des identifiants » → Clé API. Restreins-la à ton site (HTTP referrers).
    4. 
          
  4. Colle la clé ci-dessus. Quota gratuit : 10 000 unités par jour, environ 100 recherches.
    5.
